# Organisasjonskart

Firmakart og felles kart velges som før. Forklaring om forskjellen ligger i Om firmakart og felles kart. Introduksjon og fire statistikker deler bredde når det er plass; på mobil brytes de. Slik bygger du firma, styre og underavdelinger kan utvides før redigering. Filtre, redigering, lagring, plassering, HR-bekreftelse, felles kart og PDF-motor er uendret.

Eksisterende organization-react-check.mjs kontrollerer faktiske React-komponenter mot syntetisk transport: scope, sen respons, rettigheter, utkast, HR og redigering. Geometri må i tillegg kontrolleres i innlogget Preview ved flere skjermbredder.
