# Expo ProffDok – Befaring / Tilbud / Aksept

Denne modulen utvikles separat fra eksisterende produksjonsfunksjonalitet.

## Formål

Digital arbeidsflyt:

Forespørsel → Befaring → Tilbud → Kundevisning → Aksept → Aktiver som ProffDok-prosjekt

## Viktige prinsipper

- Mobil først
- Registrer informasjon én gang
- Gjenbruk informasjon videre i arbeidsflyten
- Manuell prising i MVP 1.0
- Ingen automatisk kalkulasjon
- Ingen AI-genererte priser
- Sendte tilbudsversjoner skal ikke overskrives
- Kundeaksept skal knyttes til eksakt tilbudsversjon
- Sak og ProffDok-prosjekt er separate objekter
- Prosjekt opprettes kun etter aktiv brukerhandling
- Eksisterende produksjonsfunksjonalitet skal beskyttes
