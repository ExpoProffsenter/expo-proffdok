# KS/HMS: kladd og gjennomgang – reviewutkast

36 sekunder, tre scener, norsk tekst, ingen lyd. Faktiske skjermbilder fra innlogget sandbox i kontrollpunkt4, 13.11.2026; ingen nye UI-prøver utført for filmen. Kandidat demo3d65c0e0. Ikke publisert i Hjelp, ikke en komplett SJA-/risiko-/kontrollveiledning.

Samme renderer og hvite pekerform som fristutkastet; her står pekeren i ro over opptakets opprinnelige peker. Løpenummer genereres1–3. Ingen klikkring eller påstand om utført klikk. Den hvite pekeren dekker den opprinnelige pekeren; opprinnelig blå markering rundt den er beholdt. Skjermbildene er ikke retusjert. Bilder/kildedata er syntetiske; ingen token.

Kontrollert mot kontrollpunkt4: lokal SJA-kladd gjenåpnet, risiko25/4, kontrollkladd etter reload. Filmen viser ikke serverlagring, fullføring, signatur, PDF eller opprettet RUH. Verken bilde eller tekst skal brukes som attest på utført HMS-arbeid.

Bygg: `python render.py` med Pillow og ffmpeg. Kilder i assets; scener, VTT og renderer følger. Endelig film krever full flyt, lesbarhet på mobil, original PROFFDOK-VIDEO-1.0-mal og nye rene pekerkilder før apppublisering. Ingen appkode endret.
