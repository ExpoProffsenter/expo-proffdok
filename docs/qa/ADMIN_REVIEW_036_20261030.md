## Åpent konkret miljøfunn

Systemadminens arbeidsfirma-/HR-/KS-tilgangskontroller i firma-modal viser faktisk feilen «Could not find the function public.list_managed_work_profiles without parameters in the schema cache». Dette er observert i Sandbox-bundet Preview på uendret bdcbd6b3. Det beviser ikke Production-tilstanden eller at andre tilgangs-RPC-er feiler. Ingen rolle-/tilgangsendring er forsøkt. Status **åpen**; krever separat lesende miljøundersøkelse og eventuelt eget testet reparasjonsgrunnlag. Ikke skjul feilen i CSS eller erklær tilgangsreisen ferdig. Denne presentasjonspakken endrer ingen funksjon, migration eller serverkonfigurasjon.

## Automatisert og visuell kontroll

Bolig762 inkluderer åtte bredder, manager/leser og eksplisitt før/etter uten økt høyde, flyttede handlinger, lavere prosjektliste eller ekstra scroll. Systemadmin63 bruker den faktiske imperative adapteren og dens injiserte CSS, med syntetiske eksisterende felt/save-handlers. Den bevarer dirty-close, feil, retry, Escape, DOM/kladd og scrolling. Både gammel bildevariant og gammel modalramme feiler de nye målkravene før rettelse. Bilde- og admin-skjermbilder er inspisert. Samlet app-UX1769 og eksisterende firmaadmin52PASS. Full CI og faktisk ny innlogget layoutverifisering kvitteres i PR295, uten at dette lukker alle145 helappreiser.
