## Opptaksmanus for full A–Å

Følg samme fiktive bolig gjennom kapitlene. Bruk PROFFDOK-VIDEO-1.0 med hele appbildet, klikkmarkeringer, kort tekst og undertekster. Bruk Sandbox og testroller. Vis reelle skjermtilstander og kvitteringer. Bruk forhåndsvisning for utsending. Sølgløtt er ønsket demo når prosjektet er klart.

| Kapittel | Inngang | Skjermhandling | Opptak som skal vise resultatet |
| --- | --- | --- | --- |
| 1. Bygg prosjektet | Prosjektoversikt → Bygg nytt prosjekt | Velg bygningstype. Legg inn bygg, oppganger, etasjer og antall boliger per etasje. Kontroller forhåndsvisningen før du oppretter. | Forhåndsvisning og opprettet byggstruktur |
| 2. Avklar interne roller | Systemadmin → Firmaer og prosjekter / Firmaadministrasjon → Boligprosjekter | Systemadmin aktiverer modulen for firmaet. Firmaadmin gir den enkelte ansatte Lesetilgang eller Prosjektledertilgang. En vanlig firmarolle gir ikke automatisk tilgang til Boligprosjekter. Eksterne samarbeidspartnere får egne lenker senere. | Rollene i riktig firma |
| 3. Kontrakter og innsyn | Prosjekt → Kontrakter → Tilgang / Last opp dokument | Prosjektoppretteren med prosjektledertilgang starter det private kontraktsområdet. Under Tilgang velges navngitte personer som får lese eller administrere. Last opp originalen; bruk Ny versjon når samme dokument endres. | Privat kontrakt og versjonsliste |
| 4. Lag grunnpakken | Grunnpakker og tilvalgspakker → Grunnpakker | Lag rom og avsnitt, for eksempel fliser, innredning og dusj. Legg inn varer, bilder, varenummer og antall som inngår i standardleveransen. | Komplett standardrom |
| 5. Lag tilvalg og fordel | Grunnpakker og tilvalgspakker → Tilvalgspakker → Boligvalg | Sett opp alternativ til standardvaren eller tillegg til grunnpakken. Fordel felles oppsett til flere boliger. Åpne én bolig når du skal gjøre et individuelt unntak. | Prøvebolig og fordelingsresultat |
| 6. Fordel sjekklister | Sjekklister og dokumentasjon → Fordel sjekklister | Velg publiserte firmamaler eller prosjektets egne maler. Velg boligene eller rommene som skal få listene, og se over fordelingen før du lagrer. Samme oppsett kan fordeles til mange boliger samtidig. | Påkrevd kontroll i riktig rom |
| 7. Planlegg mange boliger samlet | Byggbildet → Velg leiligheter til stammegruppe → Fremdrift og varsler | Velg boliger som følger samme arbeid, også på forskjellige etasjer. Lagre en stammegruppe. I «Planlegg flere boliger» velger du gruppen, oppstart, aktiviteter og ansvarlige. | Gjenbruk eksisterende masseplanfilm |
| 8. Sett opp faktisk bemanning | Oppsett → Faktisk bemanning | Aktiver bemanningslisten når prosjektet skal bruke inn- og utregistrering. Prosjektleder kan registrere deltakere manuelt. Egne ansatte må være knyttet til prosjektet for å bruke sin prosjektinngang på Min side. UE bruker sin tildelte lenke. | Arbeidslag og periodeoversikt |
| 9. Gi UE og leverandører tilgang | Prosjekt → UE og leverandører → Gi tilgang | Fyll inn kontakt og bedrift. Velg funksjoner som fremdrift, sjekklister og bestillinger. Tilgangen gjelder alle aktive boliger i prosjektet, også nye; du trenger ikke velge dem enkeltvis. Opprett tilgangslenken når omfanget er kontrollert. | Forhåndsvis avgrenset tilgang med testroller |
| 10. Velg kontakt og beboerdialog | Bolig → Leilighetsinformasjon / Beboerportal | Legg til én kontaktperson per bolig. Klargjør portal og eventuelle tilbud når innholdet er kontrollert. Meldinger kan slås på for hele prosjektet eller bare enkelte boliger. | Bolig, kontakt og avtaleoversikt |
| 11. Del avtaler med beboerne | Bolig → Beboerportal / Endringer og beboeraksept | Klargjør beboerportalen, kontroller kontakten og del bare de valgene og dokumentene beboeren trenger. Et innsendt boligvalg må gjennomgås før det brukes i avtalegrunnlaget. Kontroller varer, antall, pris og svarfrist før avtalen deles. | Testbeboerens visning og aksept |
| 12. Bestill og følg leveringer | Bolig → Bestilling og levering → Klargjør varebestilling | Kontroller varelinjer, antall og valgt bolig. Utelat varer som skal kjøpes andre steder. Lagre og fortsett klargjør utkastet. Se over leverandør, leveringsadresse og vedlegg før en bestilling sendes. | Én boligordre, Cordel og Excel, registrert mottak |
| 13. Utfør og dokumenter sjekklistene | Bolig → Sjekklister og dokumentasjon | Åpne den pågående eller neste sjekklisten. Fyll ut punktene, legg til bilder og vedlegg og lagre. Last opp filene før du velger dem som dokumentasjon. Fullfør listen først når kontrollene faktisk er utført. | Utfylt kontroll med testvedlegg |
| 14. Følg avvik, meldinger og frister | Byggoversikt → Beboerdialog / Bolig → Ferdigstilling → Se åpne forhold | Bruk meldingsmerket på fasaden eller Beboerportal-kortet for å finne samtalen. Lest betyr at meldingen er sett; behandlet betyr at oppfølgingen er avklart. Åpne forhold kan knyttes til arbeid under Oppfølging i fremdriftsplanen. | Kritisk avvik og separat restpunkt |
| 15. Varsle beboerne | Fremdrift og varsler → Nytt beboervarsel | Velg hele prosjektet, et bygg, en oppgang eller bestemte boliger. Skriv innhold, tidspunkt og kontaktperson. Kontroller forhåndsvisningen. Lagre utkast sender ingenting; Last ned PDF / oppslag gir et papirvarsel. | Beboervarsel som forhåndsvisning |
| 16. Følg kontraktsøkonomien | Kontrakter → Kontraktsøkonomi | Under Kontraktssum og vilkår velger du indeks, basismåned, reduksjonsfaktor og hvilke leveransedeler som reguleres. Fakturert og a konto brukes til periodens fakturering. Fakturadatoen styrer hvilken publisert indeks som kan brukes. | A-konto og indeks på egen linje |
| 17. Vurder overtakelsen | Byggoversikt → Løpende overtakelse → Ferdigstilling av bygg | Øverst i byggoversikten ser du hvor mange boliger i valgt bygg som gjenstår og er overtatt. Åpne boliglisten, velg en bolig og vurder åpne forhold. Kontroller, avvik, aktiviteter, intern godkjenning og ubehandlede meldinger samles her. | Sperre, restpunkt og protokoll |
| 18. Lever dokumentasjon og følg opp | Sjekklister og dokumentasjon → Samlet PDF og ZIP | Ta ut dokumentasjonen per bolig, bygg eller prosjekt. PDF-en viser status og prosjektleders vurderinger. ZIP-en inneholder også de lagrede originalfilene og historikken. Ekstern FDV følger som lenker. | Samlet PDF, ZIP og FDV-lenker |
