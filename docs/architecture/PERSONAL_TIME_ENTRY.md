# Personlig inngang til firmaets timeføring

Min side får HR-kontekst fra eksisterende tilgangseier. Den leser firmaets eksisterende `time_tasks_get` gjennom `createTimeSession`, og krever eksakt bruker/firma i svaret. Firmaets lagrede `enabled` styrer personlig navigasjon og kort. HRs administrasjon og separat mobil-opt-in beholder sine eksisterende eiere.

Gaten eier bare om inngangen kan vises. Den utfører ingen kommando og lagrer ingen autoritet i nettleseren. Ved revalidering beholdes samme scopes navigasjonsfaktum, mens nyttelast og synlighet nullstilles. Den native arbeidsflaten eier egen frisk data og kladd. Portalcontexten gjør at skjuling også omfatter den native registreringsdialogen. Et bekreftet avslag avmonterer arbeidsflaten; dens eksisterende scoped RAM-kladd beholdes etter dagens kontrakt.

Alle asynkrone svar må tilhøre gjeldende effect/epoch og riktig kontekst. Firmabytte/revokering kan derfor ikke gjenopplive gammel inngang eller timeinnhold. Lesefeil gir en eksplisitt ny kontroll i den valgte arbeidsflaten. Ingen server-, RLS-, settings- eller kommandoarkitektur endres.
