# Kapittel- og rutinedekning

Kontrollert 2026-10-05 mot begge originale vedlegg. Sidetall er PDF-sider (1-basert). Hele 148 + 127 sider er tekstuttrukket; organisasjonskart og innfelte rutiner er visuelt kontrollert. Titler er kildeidentifikatorer, ikke ProffDok-tekst. Ingen personlige svar, bilder eller skjemaoppsett er importert.

105 + 88 innholdsoppføringer, 17 bare i kvalitetshåndboken, 16 ekstra underliggende temaer og 4 metadatarader. Alle kildetema er bevart. Dobbel beredskapsplan beholdes som K013/K014. Personalhåndboken har ingen egen unik TOC-tittel, men andre sideforløp, individuelle bekreftelser og enkelte utvidelser (bl.a. kjemikalier/PPE/løft). Den er ikke identisk med kvalitetshåndboken.

A = håndbok og tilgang; B = utførelse/risiko/avvik og faginnhold; C = varsler/PDF/rapport; D = personal/kompetanse/stoffkartotek. Status her er innholdsstatus; en funksjon som kan lagre rutinen innebærer ikke at temaet er ferdig skrevet. Kilden er ikke brukt som bevis for gjeldende regelverk. Kravnøkler og leveransetrinn er forklart i `PLAN.md`.
